# Hiddenbench

<p class="eyebrow">Deciding when the facts are distributed</p>

A hidden-profile task: the information needed to reach the correct answer is split
across the participants, and no single agent holds enough to identify it alone. The
answer is recoverable only if the private facts that rule out the alternatives are
surfaced.

This is the hardest shape CONCORD encounters, because the disagreement is not about
judgement but about **which facts each agent can see**.

## What to watch for

- Every opening position is reasonable on the information its author holds.
- Agreement is reached on the shared evidence, not on the loudest position.

!!! note "Certified is not correct"
    These tasks are the one case in the benchmark where a ground truth exists.
    CONCORD certifies that every agent cleared its satisfaction floor; that is a
    different claim from having chosen the right site.

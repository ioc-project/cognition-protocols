# ACCORD — intent alignment

<p class="eyebrow">Establishing shared intent before work begins</p>

Agents that use the same terms are generally assumed to share the same understanding
of them. Where they do not, the mismatch is not detected: the field names and types
match, so no validation fires, and the divergence becomes visible only in the output.

ACCORD assembles a shared System Model by coverage rather than negotiation, and
emits the locked **Intent Contract** — CONCORD's precondition.

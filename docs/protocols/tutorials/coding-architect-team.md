# Coding Architect Team

<p class="eyebrow">Architects reaching one design decision</p>

A team of architect agents is asked to settle a design question on which each of them
is correct from a different position. The recording follows the protocol run from the
opening proposals through to the committed decision.

Two recordings cover the same scenario under different agent runtimes, which is the
point of showing both: the protocol is specified independently of the harness that
runs it, so the exchange is the same in each.

## One Claude agent per architect

Each architect is an individual agent, and the protocol skills are carried by the
agents themselves.

## What to watch for

- Each opening proposal is defensible from the role that made it, and leaves another
  role worst off.
- The committed design is not the first choice of any single architect.

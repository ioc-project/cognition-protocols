# Guided tour

<p class="eyebrow">See ACCORD and CONCORD in action, without running them</p>

A step-by-step tour of recorded runs of four Claude Code instances (an initiator and three
specialists) talking through [AgentBridge](../tutorials/agentbridge/index.md) to decide how to build
a notification service. The tour compares the same task with no protocol and with ACCORD then
CONCORD, explaining each step as it happens. You can also pick any run in the player: no protocol, or
ACCORD then CONCORD, on Sonnet 5.5 and Haiku 4.5. Every message is a real captured
message or reply.

# Tutorials

<p class="eyebrow">Running a Cognition Protocol end to end</p>

Step-by-step walkthroughs that run a protocol on a real decision. Both use the same
scenario, three specialists with conflicting criteria that must agree on how to build a
notification service, and the skills from the [Getting Started](../protocols/getting-started.md) page.

<div class="grid cards" markdown>

-   **[CONCORD over AgentBridge](agentbridge.md)**

    ---

    Four independent Claude Code processes joined by AgentBridge and a SLIM message bus,
    each sandboxed. Agents can live in separate processes, containers or harnesses.

-   **[CONCORD with Claude Code agent teams](agent-teams.md)**

    ---

    The quickest way to try a protocol: a lead and three teammates in your local Claude
    Code, with no message bus.
